Local Image Saver

Privacy Policy

How Local Image Saver finds, converts, copies, and downloads user-selected images while keeping processing on the user's device.

Effective July 15, 2026

Overview

Local Image Saver is a browser extension that helps users find images on the active webpage, identify higher-resolution candidates, save original files, convert images to PNG, JPG, or WebP, copy an image, and download selected images. This Privacy Policy explains what the extension handles and how that information is protected.

Privacy summary

Image discovery, conversion, clipboard preparation, and ZIP creation run locally in the browser. Local Image Saver does not require an account, upload images or browsing data to a developer-operated server, include analytics or advertising trackers, or sell or transfer user data.

Information handled by the extension

Local Image Saver accesses a webpage only after the user opens the extension on the active tab or chooses one of its image context-menu commands. To provide the requested feature, it may temporarily process:

  • Image URLs, preview URLs, dimensions, formats, filenames, alternative text, and image-source metadata found on the active page.
  • Image files fetched directly from the website or image host when conversion, copying, or ZIP creation is requested.
  • User-selected download format, quality, filters, language, subfolder, and related extension preferences.

The extension does not collect or retain general browsing history, account credentials, form contents, or unrelated webpage content.

How information is used

Website and image information is used only to display image choices and complete the action requested by the user. The extension does not monitor tabs in the background. A request to an image host occurs only when needed to retrieve the selected image; that request goes directly from the browser to the website or content-delivery host, not through a Good Choice server.

Storage and retention

Local Image Saver stores extension-only preferences in the browser's local extension storage. It does not maintain a library of viewed or downloaded images. Temporary image data and object URLs used during conversion, copying, or ZIP creation remain in the browser and are released after processing or when the extension context closes. Downloaded files remain wherever the user or browser chooses to save them.

Browser extension permissions

  • activeTab provides temporary access to the tab where the user opens Local Image Saver.
  • scripting runs packaged image-discovery logic in that active tab after the user opens the extension.
  • contextMenus adds user-invoked commands for saving an image in its original format or converting it to PNG, JPG, or WebP.
  • downloads saves files only after the user requests a single-image or batch download.
  • clipboardWrite writes a user-selected image to the system clipboard only after the user clicks Copy.
  • offscreen provides a hidden local extension document for image conversion and ZIP creation.
  • storage saves extension-only preferences on the user's device.

Optional access to an http:// or https:// image host is requested only when the selected conversion or copy operation needs it. The browser displays the request, and granted host access can be revoked from Local Image Saver's Settings page or the browser's extension settings.

Data transmission and sharing

Local Image Saver does not transmit image contents, image URLs, webpage details, browsing history, settings, or usage records to Good Choice or to analytics, advertising, or data-broker services. Data leaves the extension only through the user-requested browser download or system clipboard action, or through a direct request to the website hosting the selected image.

Remote code, analytics, advertising, and accounts

This version does not use remotely hosted executable code and does not include analytics, behavioral tracking, advertising, affiliate injection, user accounts, cloud synchronization, or payment processing. All executable logic is included in the extension package distributed by the browser store.

Browser store data use

When distributed through the Chrome Web Store or Microsoft Edge Add-ons, Local Image Saver uses information received from browser extension APIs only to provide its user-facing image features. User data is not used or transferred for advertising, creditworthiness, lending, or any unrelated purpose.

User choices

Users control when a page is scanned, which images are selected, whether optional image-host access is granted, and whether an image is copied or downloaded. Users can revoke granted host access, clear extension preferences, or remove all extension data by uninstalling Local Image Saver.

Changes to this policy

If this policy or the extension's data practices materially change, the updated policy will be published on this page with a revised effective date. Applicable browser-store disclosures will also be updated when required.
