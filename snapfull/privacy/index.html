SnapFull

Privacy Policy

How SnapFull processes full-page screenshots entirely on your device without collecting or transmitting your webpage content or browsing data.

Effective July 15, 2026

Overview

SnapFull is a browser extension that captures a user-selected webpage as one full-page screenshot and provides on-device tools to annotate, copy, download, and organize the resulting image. This Privacy Policy explains the limited local processing required for those features.

Privacy summary

SnapFull does not collect user data from the user's device or transmit it off-device. Screenshots and limited page information are processed only inside the user's browser and are never transmitted to, received by, or accessible to the developer or any third party.

No collection of user data

SnapFull does not collect, receive, upload, sell, share, or transfer personal information, website content, browsing history, or screenshot data. It does not use analytics, telemetry, advertising trackers, user accounts, cloud synchronization, or developer-operated data servers.

Local processing initiated by the user

SnapFull accesses a webpage only after the user explicitly clicks the extension button or invokes its keyboard shortcut on the active tab. To provide the requested screenshot and local library, the extension processes the following information entirely on the user's device:

  • The rendered pixels of the selected webpage needed to create the screenshot.
  • The page title, source URL, and hostname used to identify the capture in the local library.
  • The screenshot dimensions, file type, file size, and capture time.
  • The user's local annotations and edits applied to the screenshot.

How locally processed information is used

Locally processed website content and page information are used solely to create the screenshot requested by the user, provide annotation and export tools, and identify the capture in the on-device library. SnapFull does not request or use the chrome.history API, monitor tabs or browsing activity in the background, build a browsing profile, or access any page until the user starts a capture.

Storage and retention

Completed screenshots, thumbnails, edits, and associated metadata are stored only on the user's device in the browser's local extension database. SnapFull also stores extension-only preferences such as the selected interface language. This local information is not synchronized or made available to the developer. Captures remain on the device until the user deletes them, clears the extension's data, or uninstalls SnapFull.

Browser extension permissions

  • activeTab provides temporary access to the tab on which the user invokes SnapFull.
  • scripting runs the packaged capture script in that tab to measure and scroll the page, temporarily prevent repeated sticky elements, and restore the page after capture.
  • Optional downloads access is requested only after the user chooses to download an exported image. If it is not granted, SnapFull uses a normal browser download instead.
  • storage saves extension-only preferences and local state on the user's device.
  • unlimitedStorage allows user-created full-page captures to remain in the on-device library without a small extension storage quota.

SnapFull does not use remote executable code. All executable logic is included in the extension package.

Data transmission and sharing

SnapFull does not transmit screenshot contents, page URLs, page titles, browsing information, local annotations, or library records to the developer or to third parties. The developer has no ability to view this local information. An image leaves the extension only when the user explicitly chooses to copy it or download it to a destination under the user's control.

Analytics, advertising, and accounts

This version of SnapFull does not include analytics, behavioral tracking, personalized advertising, user accounts, cloud synchronization, payment processing, or remotely hosted executable code.

Browser store data use

For browser-store disclosure purposes, SnapFull does not collect user data because no website content, browsing information, screenshot, or associated metadata is transmitted to or made accessible to the developer or any third party. The local, user-initiated processing described above is used only to provide SnapFull's visible screenshot features.

SnapFull's use of information received from browser extension APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements, and with applicable Microsoft Edge Add-ons policies. Information is never used or transferred for advertising, creditworthiness, lending, profiling, or any unrelated purpose.

User choices

Users control when SnapFull captures a page. Individual captures can be deleted from the SnapFull library at any time. Users can remove all locally stored SnapFull data by clearing the extension's data or uninstalling the extension.

Changes to this policy

If this policy or SnapFull's data practices materially change, the updated policy will be published on this page with a revised effective date. The applicable Chrome Web Store disclosures will also be updated when required.
