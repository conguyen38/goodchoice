SEO Lens

Privacy Policy

How SEO Lens handles website content and protects user privacy while providing on-page SEO and GEO analysis.

Effective July 13, 2026

Overview

SEO Lens is an on-page SEO and GEO analysis browser extension. This Privacy Policy explains what information the extension handles, why it is needed, and how it is protected.

Privacy summary

SEO Lens performs analysis locally in the browser. It does not require an account, include analytics or advertising trackers, sell user data, or send analyzed webpage content to a developer-operated server.

Information handled by the extension

SEO Lens accesses a webpage only after the user clicks the extension on the active tab. To produce the requested report, the extension may process:

  • The current page URL, title, metadata, visible text, headings, keywords, and language.
  • Links, image URLs, image dimensions, and alternative text.
  • Robots directives, canonical links, structured data, and social sharing metadata.
  • Other on-page SEO and GEO signals required to generate the report.

The extension may request the public robots.txt, sitemap.xml, and llms.txt files from the same website being analyzed. Social preview images may be loaded directly from the image URL declared by that webpage.

How information is used

Website content is processed solely to display the SEO and GEO report requested by the user. Analysis is performed locally in the user's browser. SEO Lens does not transmit analyzed webpage content, report results, or browsing activity to the developer or to a developer-operated server.

Storage and retention

SEO Lens stores only the user's selected interface language in the browser's local extension storage. Analyzed webpage data and report results remain in memory while the extension popup is open and are discarded when it closes. The language preference remains on the device until extension data is cleared or SEO Lens is uninstalled.

Browser extension permissions

  • activeTab provides temporary access to the page on which the user invokes SEO Lens.
  • scripting runs the packaged analysis function in that active tab after the user invokes the extension.
  • storage saves only the selected interface language on the user's device.

SEO Lens does not use remote executable code. All executable logic is included in the extension package.

Sharing, sale, and advertising

SEO Lens does not sell, rent, share, or transfer user data to third parties for advertising, profiling, creditworthiness, lending, or any purpose unrelated to its single purpose. The extension includes no analytics, advertising, or tracking SDK.

External links

SEO Lens includes optional links to official documentation and social-platform debugging tools. These links open only after a user action. Use of the destination website is governed by that website's own privacy policy.

User choices

Users control when SEO Lens analyzes a page by clicking the extension. Users can remove the locally stored language preference by clearing extension data or uninstalling SEO Lens.

Changes to this policy

If this policy or the extension's data practices materially change, the updated policy will be published on this page with a revised effective date. The applicable browser-store disclosures will also be updated when required.

Contact

For privacy questions or support, open an issue in the SEO Lens support repository.
